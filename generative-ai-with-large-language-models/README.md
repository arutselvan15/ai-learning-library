# Generative AI with Large Language Models

Catalog for the course knowledge base. Start with a phase overview, then work through its chapters in order.

## Course Outcome

Understand the lifecycle of a generative AI project: select a model, prompt and evaluate it, adapt it with fine-tuning or RLHF, optimize inference, and integrate it into an application.

## Course Map

| Phase | Focus | Material |
| --- | --- | --- |
| 1. Understand and select an LLM | Project lifecycle, transformers, pre-training, and compute | [Phase overview](phases/01-understand-and-select/README.md) |
| 2. Prompt and evaluate | Prompting, generation, summarization lab, and evaluation | [Phase overview](phases/02-prompt-and-evaluate/README.md) |
| 3. Adapt a model | Fine-tuning, PEFT, LoRA, and summarization lab | [Phase overview](phases/03-adapt-a-model/README.md) |
| 4. Align behavior | Human preferences, reward models, RLHF, and detoxification lab | [Phase overview](phases/04-align-behavior/README.md) |
| 5. Build an application | Optimization, RAG, tools, orchestration, and deployment | [Phase overview](phases/05-build-an-application/README.md) |

## Completion Checklist

- [ ] Define a use case and measurable success criteria.
- [ ] Compare prompting strategies and generation settings.
- [ ] Evaluate outputs with task metrics and human review.
- [ ] Compare full fine-tuning and parameter-efficient fine-tuning.
- [ ] Understand the RLHF data and optimization loop.
- [ ] Design an application using retrieval or constrained tools where appropriate.
