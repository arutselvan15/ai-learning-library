| [Google AI developer site](https://ai.google.dev/) | Provider API information; compare with the repository's [Google example](examples/google-ai.py). |
| [OpenAI API documentation](https://platform.openai.com/docs/) | Provider API information; compare with the repository's [OpenAI example](examples/open-ai.py). |
| [LangChain documentation](https://python.langchain.com/docs/) | Optional orchestration library used in the [LangChain example](examples/langchain-ai.py). |

For local dependencies, see [standalone example setup](setup.md). For the learning sequence and original course materials, return to the [chapter index](README.md). Keep API keys out of source control.
